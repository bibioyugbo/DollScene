# DollScene 3D Asset Spec

Every 3D feature already works with procedural placeholder dolls and furniture. Real assets **drop in with zero code changes**: put a `.glb` in the right folder under `public/models/` with the right file name, and the game picks it up. In dev, `/models/manifest.json` is generated live by a Vite plugin. In production it is written into the build. If a model fails to load, the placeholder is used and nothing crashes.

```
public/models/
  starters/<starterId>.glb       base characters (12)
  hair/<hairStyleId>.glb         one per hairstyle (25)
  garments/<template>.glb        one per garment template (shared by every item of that template)
  items/<catalogItemId>.glb      optional per-item override (wins over the template)
  furniture/<template>.glb       one per furniture template
  furniture/<catalogItemId>.glb  optional per-item override
  jewellery/<type>.glb           stud | hoop | barbell | ring | chain | cuff (optional; procedural fallback)
```

Ids come from code:

| What | Where the ids live |
|---|---|
| Starters | `src/shared/starters.ts`: `ada zainab imani chloe tunde kofi mathieu jaylen kemi sage remy nuru` |
| Hair styles | `HairStyleId` in `src/shared/types.ts` (e.g. `knotless-braids`, `bantu-knots`, `silk-press`) |
| Garment templates | `GarmentTemplate` in `src/shared/types.ts` (e.g. `buba`, `agbada`, `gele`, `wrapper`, `jeans`) |
| Furniture templates | `FurnitureTemplate` in `src/shared/types.ts` (e.g. `bed-double`, `vanity`, `neon-sign`) |
| Catalog item ids | `src/shared/catalog.json` (generated by `npm run catalog`) |

When a starter GLB exists, that doll renders with the real body plus any hair and garment GLBs that exist. A garment with no GLB is simply not drawn on a real body, so ship garments in batches by template. Starters without a GLB keep the full procedural doll.

---

## 1. Units, axes, scale

- glTF 2.0 binary (`.glb`), **metres**, **Y-up**, character faces **+Z**.
- Origin at the floor between the feet. A height-1.0 doll is **1.60 m** tall. The game scales the root by `body.height` (0.85 to 1.15).
- Apply all transforms before export (scale 1, rotation 0).

## 2. Shared skeleton (every starter, hair and garment)

One skeleton, identical bone **names** and rest pose across all assets. Modules are re-bound to the base skeleton **by bone name** at runtime.

```
Root
└─ Hips
   ├─ Spine ─ Spine1 ─ Spine2 ─ Neck ─ Head ─ (HeadTop_End, LeftEye, RightEye, Jaw)
   │                         ├─ LeftShoulder ─ LeftArm ─ LeftForeArm ─ LeftHand ─ fingers (Thumb1-3, Index1-3, Middle1-3, Ring1-3, Pinky1-3)
   │                         └─ RightShoulder ─ RightArm ─ RightForeArm ─ RightHand ─ fingers
   ├─ LeftUpLeg ─ LeftLeg ─ LeftFoot ─ LeftToeBase
   └─ RightUpLeg ─ RightLeg ─ RightFoot ─ RightToeBase
```

Mixamo-compatible names (without the `mixamorig:` prefix) are fine. Max **4 influences per vertex**. A-pose or T-pose rest, but the same one everywhere.

## 3. Base character (`starters/<id>.glb`)

| Mesh | Material name | Notes |
|---|---|---|
| `Body` (SkinnedMesh, includes head) | `Skin` | Base colour texture is tinted by the player's skin tone, so author it near-white with detail in value. Tattoos are composited onto this map (section 7). |
| `Eyes` | `Eyes` / `Iris` | `Iris` colour is replaced with the chosen eye colour. |
| `Mouth` or part of `Body` | `Lips` | Colour and roughness driven by lipstick and gloss. |
| `Nails` | `Nails` | Tinted with nail colour. |
| `Brows`, `Lashes` | any | Optional cards. |

Animation clip **`Idle`** (looping, 3 to 6 s) is played automatically. Optional extra clips: `Walk`, `Pose_01`…

### Morph targets (blendshapes)

The base mesh is the **neutral 0.5** value of every slider. Each slider uses a pair of morphs. The game sets `<Name>_Neg = max(0, (0.5 - v) * 2)` and `<Name>_Pos = max(0, (v - 0.5) * 2)`.

| Face | Body |
|---|---|
| `Nose`, `Lips`, `Jaw`, `Cheekbones`, `Chin`, `Forehead`, `EyeSize`, `EyeSpacing`, `EyeShape`, `Brows`, `Asymmetry` | `Shoulders`, `Waist`, `Hips`, `Bust`, `Legs`, `Muscle`, `Softness` |

Example: `Hips_Neg`, `Hips_Pos`. Garments that must follow body shape need the **same body morph names** so they deform with the body.

### Piercing sockets

Empties (no mesh) parented to the `Head` bone (or `Spine1` for body sites), named `Socket_<site>_<L|R|C>`, with **+Z pointing out of the skin**:

```
Ear:  lobe lobe-2 lobe-3 upper-lobe helix forward-helix tragus anti-tragus conch-inner conch-outer daith rook industrial flat orbital
Face: nostril high-nostril septum bridge eyebrow labret monroe medusa snake-bites smiley tongue
Body: navel dermal surface
```

`L` is the doll's own left (+X). Centred sites use `C`.

## 4. Hair (`hair/<style>.glb`)

- Skinned to the shared skeleton, mostly to `Head`. Physics or long strands may use extra bones whose names start with `Hair_`; they are kept from the module.
- Single material **`Hair`**. Its base colour texture is **replaced at runtime** by the dye texture. **UV V = 1 at the root, V = 0 at the tips.** U runs around the head (U < 0.5 is the doll's left), which is what the split dye uses.
- Alpha-tested cards are fine (`alphaMode: MASK`). Keep **edges / baby hairs** as part of the hairline module or as `Edges_<style>` meshes. Procedural edges are drawn when none exist.
- Budget: **≤ 25k tris** (braids and locs ≤ 40k).

## 5. Garments (`garments/<template>.glb`, `items/<id>.glb`)

- Skinned to the shared skeleton, modelled on the neutral body, with the same **body morph names** where shape matters.
- Material **`Fabric`**: its map is replaced by the item's pattern texture (Ankara, adire, aso-oke, kente, denim…), tiled through UVs at about 1 repeat per 25 cm. Other materials (buttons, metal, soles) are left as authored.
- Rigid accessories (sunglasses, earrings, gele, hats) may be unskinned: name the root child **`@BoneName`** (e.g. `@Head`) to attach to that bone.
- One template GLB serves every catalog item of that template. Colour and pattern come from the catalog. Use `items/<id>.glb` only for signature pieces.
- Budget: **≤ 15k tris** per garment, 1 material plus 1 trim material.

## 6. Textures and compression

- **KTX2 / Basis Universal** textures (UASTC for normals, ETC1S for colour). The transcoder is self-hosted in `public/basis/`.
- **Draco or Meshopt** geometry compression. The decoder is self-hosted in `public/draco/`.
- Sizes: body 2048² (base colour, normal, ORM), head detail allowed at 2048², hair 1024², garments 1024², furniture 512 to 1024².

```bash
# Example pipeline (gltf-transform)
npx @gltf-transform/cli optimize in.glb out.glb --compress draco --texture-compress ktx2
```

## 7. Tattoo decal UV space

Tattoos are composited onto the `Skin` base-colour map at these UV rectangles (`[u, v, width, height]`, V measured **from the top** of the image). Lay out the body UVs so each region below covers that body part, roughly undistorted. This mapping lives in `TATTOO_UV` in `src/three/doll/GlbDoll.tsx`; change both together.

| Region | Rect | Region | Rect |
|---|---|---|---|
| face | 0.02 0.02 0.20 0.20 | ribs | 0.26 0.24 0.12 0.16 |
| neck | 0.24 0.02 0.12 0.10 | stomach | 0.40 0.22 0.26 0.16 |
| chest | 0.40 0.02 0.26 0.18 | hip-l / hip-r | 0.26 0.42 / 0.38 0.42 (0.10 × 0.10) |
| back | 0.70 0.02 0.28 0.24 | thigh-l / thigh-r | 0.50 0.42 / 0.66 0.42 (0.14 × 0.18) |
| shoulder-l / -r | 0.02 0.26 / 0.13 0.26 (0.10 × 0.08) | calf-l / calf-r | 0.50 0.62 / 0.66 0.62 (0.14 × 0.16) |
| arm-l / -r | 0.02 0.36 / 0.13 0.36 (0.10 × 0.14) | ankle-l / -r | 0.82 0.62 / 0.90 0.62 (0.08 × 0.06) |
| forearm-l / -r | 0.02 0.52 / 0.13 0.52 (0.10 × 0.14) | foot-l / -r | 0.82 0.70 / 0.90 0.70 (0.08 × 0.10) |
| hand-l / -r | 0.02 0.68 / 0.13 0.68 (0.10 × 0.08) | fingers | 0.02 0.78 0.21 0.05 |

## 8. Furniture (`furniture/<template>.glb`)

- Metres, Y-up, front faces **+Z**, origin at the **floor centre of the footprint**.
- Wall items (`art-frame`, `neon-sign`, `wall-shelf`, `wall-mirror`): origin at the **centre of the back face**, so z = 0 touches the wall.
- Footprint (w × d × h) must match the catalog `furniture` spec, which is used for collisions. Change both together.
- Lamps and neon may include `KHR_lights_punctual` lights. Keep each to one light.
- Budget: **≤ 8k tris**, one 1024² texture set.

## 9. Polygon and texture budgets (mobile-first, 60 fps)

| Asset | Tris | Textures |
|---|---|---|
| Base character (LOD0) | 25–35k | 2048² ×3 (body), eyes 512² |
| Base character LOD1 (crowds, globe) | ≤ 8k | 1024² |
| Hair | ≤ 25k (braids/locs ≤ 40k) | 1024² |
| Garment | ≤ 15k | 1024² |
| Shoes / accessories | ≤ 5k | 512² |
| Furniture | ≤ 8k | 512–1024² |

Target a full dressed doll at **≤ 90k tris** and **≤ 24 MB** of GPU texture memory with KTX2.

## 10. Acceptance checklist per asset

1. Loads in the app with no console errors (`npm run dev`, open `/create`).
2. Morph sliders move the mesh both ways from neutral. Garments follow `Hips`, `Waist`, `Bust`.
3. Hair dye modes (ombré, split, bleached tips) read correctly: roots at the top.
4. Tattoos appear on the right body part in the Tattoos tab (body shown undressed).
5. Piercing sockets sit on the skin and point outward.
6. A furniture piece's footprint matches the grid ghost in build mode.
